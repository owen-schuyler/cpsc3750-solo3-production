Team Project

Persistent Waters

Multiphase Battleship-style web game

Persistent Waters lets players run a turn-based naval strategy match in the browser with persistent game state and clear move feedback. It is interesting because the project grew from a deployed Flask API into a playable frontend with live board updates, firing flow, and match history across team-hosted phases. I kept the backend rules authoritative so routing, game logic, turn enforcement, and deployment could support multiple interfaces without duplicating the core match behavior.

Phase 1

Live Link

Backend API and Game Foundation

Phase 1 established the deployed game service, including Flask routes, persistent match data, and server-side rules for creating games and resolving turns. It gave the team a stable contract to build against because every move went through the same backend validation path instead of trusting the client. My architecture decision was to keep turn enforcement and firing resolution inside the backend so future phases could add interfaces without weakening the game rules.

My Contributions

  • Backend architecture and route organization
  • Game logic for match state and firing results
  • Turn enforcement to prevent out-of-order play
  • Render deployment setup and production routing checks

Phase 2

Live Link

Playable Frontend and Live Match Flow

Phase 2 added the gameplay view players use to inspect the board, fire at coordinates, and follow recent moves during an active match. It is interesting because the frontend has to stay responsive while still respecting a backend-authoritative turn system and repeatedly refreshed game state. My key architecture decision was to use polling around the live board and move history so players could see fresh match state without adding heavier realtime infrastructure for this checkpoint.

My Contributions

  • Gameplay view structure and live board integration
  • Firing mechanic connected to backend move validation
  • Polling for refreshed board state and turn updates
  • Move history display and design polish for the play flow
